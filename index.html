E-Mail Manager

Utility that scans inbox(es) and replies to messages with text, images, and attachments based on user-specified rules and schedule.

What it does

  • Rules. Decide which e-mails get your reply, which only get a label, and which wait for you.
  • Reply. Write your message in a rich text editor, with images, the sender's name and your Gmail signature.
  • Attachments. Attach your résumé, price list or any other files to every reply.
  • After sending. Label, archive or mark as read, and never answer the same conversation twice.
  • Schedule. Run every few minutes or hours, once a day, or only when you click Run now.
  • Report. A spreadsheet of everything that was done is e-mailed to your inbox after each run.

Your data

Everything runs inside your browser. E-mail is read only through Google's official Gmail API and is never sent to the publisher or anyone else. The extension never deletes e-mail. Read the full privacy policy.

Get it

E-Mail Manager is a Chrome extension. The source code is on GitHub.
